# PharmaSeek 💊

A smart medication finder that helps users locate needed 
medications at nearby pharmacies — combining location-based 
search with AI-powered medicine recognition to eliminate 
the frustration of pharmacy-hopping.

## Motivation
Finding a specific medication in Tunisia often means visiting 
multiple pharmacies with no guarantee of availability. 
PharmaSeek solves this by combining real-time pharmacy stock 
data, geolocation, and AI to give users the fastest path to 
their medication.

## Features
- Search medications by name
- Location-based results — closest pharmacy with stock appears first
- AI-powered box scanner — point your camera at any medication 
  box and the app automatically extracts the medicine name
- View pharmacy details, distance, and availability
- REST API backend serving the mobile/web frontend

## Tech Stack
- Frontend: React
- Backend: Java Spring Boot
- Database: MySQL
- Architecture: REST API
- AI: OCR / image recognition for medication box scanning
